🌐 SERVER VIRTUAL HOST 2: domain2.local

Chào Mừng Đến Với Web 2

Trang Landing Page độc lập chứng minh Nginx phân biệt thành công nhiều tên miền khác nhau trên cùng một cổng 80 (Name-based Virtual Hosting).

🎯 Mục Đích Triển Khai

Đây là website thứ hai được phục vụ bởi Nginx container. Mặc dù cả hai website đều lắng nghe trên cùng cổng 80 và chia sẻ chung một địa chỉ IP, Nginx đã định tuyến chuẩn xác dựa vào tiêu đề Host trong gói tin HTTP request.

  • ✓ Web 1: domain1.local → Quản lý sinh viên & Proxy API
  • ✓ Web 2: domain2.local → Landing Page thông tin
  • ✓ Bảo mật & Tách biệt: Thư mục mã nguồn và access log riêng biệt

⚙️ Cấu Hình Nginx Tương Ứng

Khối server được định nghĩa trong nginx/conf.d/default.conf:

server { listen 80; server_name domain2.local; root /usr/share/nginx/html/web2; index index.html; }

👉 Khi truy vấn tới http://domain2.local, Nginx trả về tài nguyên trong /web2 mà không bị xung đột với /web1.

🛠️ Hướng Dẫn Thử Nghiệm Domain Ảo

Để kiểm tra tính năng Virtual Host trên máy cá nhân, thêm dòng sau vào file hosts:

# Trên Windows: C:\Windows\System32\drivers\etc\hosts # Trên Linux/macOS: /etc/hosts 127.0.0.1 domain1.local 127.0.0.1 domain2.local

Sau đó truy cập trình duyệt tại http://domain1.local và http://domain2.local để kiểm chứng hai giao diện khác nhau hoàn toàn.
