Nhấn nút "Tải Dữ Liệu" để thực hiện gọi API qua Reverse Proxy.
Cơ chế hoạt động: Trình duyệt gửi HTTP GET request đến /api/tacke cùng origin. Nginx tiếp nhận, đóng vai trò Reverse Proxy điều phối luồng tới container nodered:1880/api/tacke trên mạng bridge nội bộ Docker, kèm tiêu đề CORS tiêu chuẩn.
