Trang Chủ Web 1 - Lập Trình Web

Hệ thống gọi API phân tán qua Nginx Reverse Proxy & Node-RED Backend

Virtual Host: domain1.local (hoặc localhost)

Danh Sách Sinh Viên (Dữ Liệu Từ Node-RED API)

Endpoint: /api/tacke → Reverse Proxy tới http://nodered:1880/api/tacke

Chờ gọi API
Hạng Họ Và Tên Sinh Viên Đã chi So với trung bình
Nhấn nút "Tải Dữ Liệu" để thực hiện gọi API qua Reverse Proxy.
Thuật toán API: Node-RED tính tổng, trung bình, trung vị, xếp hạng (đồng tiền thì đồng hạng), lọc theo tên không dấu / khoảng tiền / top N, và tìm danh sách chuyển khoản ít giao dịch nhất để mọi người chi bằng nhau (tham lam: người nợ nhiều nhất trả cho người được nhận nhiều nhất).
Cơ chế hoạt động: Trình duyệt gửi HTTP GET request đến /api/tacke cùng origin. Nginx tiếp nhận, đóng vai trò Reverse Proxy điều phối luồng tới container nodered:1880/api/tacke trên mạng bridge nội bộ Docker, kèm tiêu đề CORS tiêu chuẩn.
